## 1. 概念定義
在音樂資訊檢索（MIR）與熱門歌曲預測論文中，研究者常透過 Spotify Web API 或 Librosa 提取以下聲學特徵：
- **BPM (Tempo)**：每分鐘節拍數，反映歌曲速度感。
- **Danceability（可舞性）**：0.0 到 1.0，綜合節奏穩定度、節拍強度與規律性評估適合跳舞的程度。
- **Energy（能量值）**：0.0 到 1.0，衡量歌曲的強度與活躍度（如響度、音色動態範圍）。
- **Valence（情緒效價）**：0.0 到 1.0，數值越高代表聽感越正向、歡快；越低則越悲傷、陰鬱。
- **Loudness（響度）**：以分貝（dB）計算的平均音量，與「響度戰爭（Loudness War）」高度相關。
